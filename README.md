# README.md

## TaskFlow — Корпоративный задачник

**TaskFlow** — это учебное веб-приложение, разработанное для автоматизации учёта и контроля выполнения задач в компании. Проект создан на основе существующего веб-чата WebChat и адаптирован под нужды управления проектами.

Проект сдан в рамках учебного задания для компании ООО «Айти Сервис».

---

###  Описание проекта

В компании отсутствовал единый инструмент для управления задачами, что приводило к потере информации и срывам сроков. TaskFlow решает эту проблему, предоставляя простой интерфейс для создания, просмотра и отслеживания задач в рамках проектов.

**Технологии:**
*   **Backend:** ASP.NET Core 8.0 (Razor Pages), Entity Framework Core.
*   **База данных:** SQL Server LocalDB.
*   **Frontend:** HTML5, CSS3, Bootstrap 5.

---

###  Критерии приёмки

Проект считается успешно сданным, если выполняются следующие условия:
1.  Приложение запускается командой `dotnet run` без ошибок.
2.  При первом запуске автоматически создаётся база данных.
3.  Открывается страница `/Tasks`, отображающая таблицу задач.
4.  Работает форма создания новой задачи по адресу `/Tasks/Create`. После отправки задача появляется в общем списке.
5.  Для каждой задачи в списке есть кнопка «Выполнено», которая меняет её статус на `Done`.
6.  Данные (задачи и проекты) сохраняются в базе и не теряются после перезапуска сервера.
7.  Интерфейс аккуратный, использует стили Bootstrap, нет сломанных элементов.

---

###  Инструкция по запуску

Для запуска проекта на вашей машине выполните следующие шаги:

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/<ваш_логин>/TaskFlow.git
    cd TaskFlow
    ```

2.  **Восстановите зависимости:**
    В терминале выполните команду:
    ```bash
    dotnet restore
    ```

3.  **Примените миграции базы данных:**
    Это создаст необходимые таблицы (Users, Projects, Tasks, UserProjects) в SQL Server LocalDB.
    ```bash
    dotnet ef database update
    ```
    *Примечание: Если вы используете Visual Studio, можно также запустить проект, и миграции применятся автоматически.*

4.  **Запустите приложение:**
    ```bash
    dotnet run
    ```

5.  **Откройте браузер** и перейдите по адресу: `https://localhost:7005` (или другому порту, указанному в консоли).

###  Структура проекта

Проект был получен путём адаптации существующего приложения WebChat. Основные изменения коснулись моделей данных и интерфейса.

*   **Модели (Models):** Переименованы сущности `Message` -> `Task`, `Room` -> `Project`, `UserRoom` -> `UserProject`.
*   **Контекст данных (Data/AppDbContext.cs):** Обновлены `DbSet` для работы с новыми сущностями и настроены их связи.
*   **Сервисы (Services/TaskService.cs):** Логика работы с задачами (создание, получение списка, изменение статуса).
*   **Страницы (Pages/Tasks, Pages/Projects):** Реализованы Razor-страницы для отображения списков и форм.
